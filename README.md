# MakiMate: Socially Interactive Robot

Senior design team project for ECE/ME 4999 at Oakland University, Winter 2026.

## Project overview

MakiMate extends an existing open source social robot platform. The team used a Raspberry Pi 5 and ROS 2 to improve how the robot identifies and responds to people. The system combines camera and microphone input to track the active speaker, process speech, generate conversational responses, and control the robot's movements.

The team also designed new arms and a tablet-compatible torso. Those mechanical designs were not physically assembled during this project.
